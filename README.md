## ⚙️ How This Works

This repo is powered by **[dsa-autopilot](https://github.com/MridulSharma02/dsa-autopilot)** — a private automation engine that:

1. 📥 Picks the next solution from a queue
2. 🔍 Fetches full problem details from LeetCode
3. 📝 Generates a beautiful markdown file
4. 🚀 Pushes it here every night at **midnight IST**
5. 🗂️ Archives the solution automatically

Zero manual effort. Maximum consistency.
